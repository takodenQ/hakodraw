# HakoDraw

同じ形を多方向から描くための、時間制限付き立体クロッキーアプリ。紙や普段使っている描画ソフトを併用します。

## 起動

Node.js 22.12以上（検証環境22.16）とnpmを使用します。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173 を開きます。

```sh
npm run build      # TypeScript検査と本番ビルド
npm run preview    # distをローカルで確認
npm test           # 練習状態と設定データの単体テスト
npm run test:e2e   # ブラウザテスト（Microsoft Edgeを使用）
```

E2Eは起動済みの5173番サーバーを再利用します。未起動なら開発サーバーを立ち上げます。CIでは先にEdgeをインストールします。ビルド結果は `dist/` に出力され、静的ホスティングで公開できます。認証・API・DBは初版にはありません。

## 初版の機能

- Three.jsの透視投影で、厚みのない正方形を両面・辺付きで表示。
- Y-up、初期軸Y、カメラ+Z、正方形XY平面。
- 12問×30秒を初期値とし、360°を問題数で分割。最後の重複角度は出題しません。
- 問題間を0.5秒で回転。回転終了後に計時開始。
- 前後移動、一時停止・再開、途中終了、タブ非表示時の自動停止。
- 開始前の固定プレビュー、画面固定グリッド、回転するローカル軸。
- 折りたたみ表示設定。軸OFFでも開始前は表示。
- 太陽／月の単一ボタン。初回は端末配色に追従し、手動変更後は選択を保存。
- 残り10秒の穏やかな点滅バー、2秒のお祝い演出、動きを減らす設定への対応。
- ブラウザ保存、不正・破損データの補正、保存不可時の継続利用。

## 構成と責務

| ファイル | 責務 |
|---|---|
| `src/session.ts` | 練習状態の純粋な遷移。React・Three.js・ブラウザAPIに依存しない |
| `src/useSession.ts` | 単調時計と描画フレームから状態管理へイベントを送る |
| `src/settings.ts` | 設定の型、バリデーション、ブラウザ保存 |
| `src/scene/target.ts` | 正方形の形状と材質、資源解放 |
| `src/scene/renderer.ts` | カメラ、対象の向き、軸、描画。問題送りは決めない |
| `src/ModelView.tsx` | Three.jsのライフサイクル、グリッド・軸ラベル・お祝い表示 |
| `src/App.tsx` | 設定フォーム、操作、配色、画面状態 |
| `src/styles.css` | ライト／ダークのデザイントークンとレスポンシブ配置 |

## 状態設計

`setup → running → rotating → running → … → complete`

- `paused` は残り時間を保持します。
- 回転中は前後移動と一時停止を無効化し、終了は可能です。
- 一時停止中に前後移動すると `rotating → paused` になります。
- タブを隠すと自動停止。回転途中なら目標角度に着地して停止します。
- 更新後は設定だけ復元し、セッションは復元しません。
- タイマーはフレーム数ではなく `performance.now()` の期限で計算します。
- 遅い端末で回転のフレームが遅延しても、着地後の制限時間は省略しません。

## 今後の拡張

外部モデルの読み込みは初版の対象外です。将来は `target.ts` の生成対象と同じ境界にGLBローダーを追加し、向き・原点・サイズ補正を行います。元のモデル材質、表示プリセット、練習状態は分離します。人体と補助形状は共通の回転ルートに入れ、別々に表示を制御する構成にできます。

カメラの設定は焦点距離50mm、filmGauge既定35、正方形の画角、距離5.5、対象辺長2を基準にしています。「写真の50mmと同一の見え方」や学習効果を保証する値ではなく、表示を再現するための実装値です。

今回確認する端末はデスクトップのブラウザエミュレーションです。実機スマホでのGPU・バッテリー・長時間使用の評価は別途行ってください。
