# HakoDraw デザイン方針

更新日：2026-09-29

## コンセプト

HakoDrawは「光のある静かなアトリエ」と「透明な製図器具」をモチーフにする。ガラスは装飾ではなく道具の素材として限定的に使い、練習対象とユーザーの線を常に最も明瞭に表示する。

## 画面の階層

1. 観察面・描画面：最も強いコントラストを持つ不透明な製図面
2. 進行操作：開始、一時停止、前後移動、残り時間
3. 練習条件：対象、軸、問題数、秒数
4. 調整項目：構図、焦点距離、補助表示、面

外枠、モード選択、設定面には半透明素材を使う。3Dビューと描画キャンバスには背景ぼかしを重ねない。暖色テーマは朝のアトリエ、暗色テーマは夜の作業机をイメージする。

## UI基盤

- 高度な選択部品が必要になった場合はBase UIを第一候補とし、通常CSSで外観を定義する。
- 予定された短い動きはCSSで実装する。
- 割り込み可能なジェスチャーや動的な移動が必要な場合は、Motion（`motion/react`）を使う。`MotionConfig reducedMotion="user"` で「動きを減らす」設定に従う。
- **Rare UI**（rareui.in、MIT）を採用した。部品は依存としてではなく、`src/components/rareui/` にソースをコピーして所有し、このアプリ用に調整して使う（CLIの `npx rareui add` か、`https://rareui.in/r/<部品名>.json` から取得）。
  - `AnimatedTab`：練習モードのタブ。選択ピルがばねで滑らかに移動する。
  - `GlassShimmerButton`：主要な行動ボタン（練習スタート、はじめる、次のおすすめ）。光が数秒に一度横切る。
  - `LiquidTooltip`：メダルの名前を、ホバーできる端末だけでふわっと表示する。
  - 調整の方針：`framer-motion`→`motion/react`、Next.js専用の記述（`<style jsx>` など）をCSSへ、固定色をアプリのCSS変数へ、`nav`・`aria-current`・`disabled` などのアクセシビリティを追加する。
- **Tailwind CSS v4**は Rare UI の部品を動かすためだけに使う。`app.css` でリセット（preflight）を読み込まず、既存のCSSを `app` レイヤーに、Tailwind のユーティリティを上位の `utilities` レイヤーに置く。`dark:` は `data-theme=dark` に従う。新しい画面や部品の見た目は、これまでどおり通常のCSSで書く。
- アイコンはLucide Reactを継続する。

## 視覚トークン

- 背景：低彩度の暖色または寒色グラデーションと薄い製図グリッド
- ガラス：半透明面、明るい上端、細い境界、柔らかな影
- 製図面：高い不透明度、弱い内側の光、明瞭な輪郭
- 角丸：外枠26px、主要パネル16〜18px、操作部品12px
- アクセント：ライトは琥珀色、ダークは青緑色
- 軸色：X赤、Y緑、Z青を維持する

## ライトとダークの表現（`rich.css`）

- 背景：ゆっくり動くオーロラ（ライトは桃・ミント、ダークは青緑・藍・紫）。ダークは星明かりの点も重ねる。
- 外枠・カード：縁がほのかに光るガラス。ホバー（精密ポインターのみ）で少し浮き、アクセントの光をまとう。
- 「今日のおすすめ」：縁を光がゆっくり周回する。
- 主要ボタンとタブの選択ピル：ライトは琥珀のグラデーション、ダークは青緑のグラデーションに外側の光。配色ごとのトークン（`--cta-bg`、`--tab-active-shadow` など）で切り替える。
- 進み具合とカレンダー：グラデーションと柔らかな光。今日の枠は静かに脈打つ。
- メダル：ランクごとの背景の光、ホバーのきらめき、獲得直後のふわふわ、レジェンドの色相の移ろい。
- 配色の切り替え：対応ブラウザでは View Transitions で全体をなめらかに移り変わらせる。
- 装飾は、3Dビュー・描画キャンバス・タイマーより目立たせない。動きを減らす設定では、背景・光・きらめきの動きをすべて止める。

## 動き

- 頻繁な操作には装飾的な移動を加えない。
- 押下は120〜140msの`scale(.97)`で入力を受け取ったことを伝える。
- 登場には`cubic-bezier(.23,1,.32,1)`を使い、UIの遷移は300ms以内にする。
- ホバーによる変形はマウスなどの精密ポインターに限定する。
- `prefers-reduced-motion`では位置と変形の動きを停止する。
- 完了演出は頻度が低いため、現在の小さな祝福表現を許容する。

## 確認基準

- ライト・ダークの両テーマで本文と操作ラベルが読める。
- 面の不透明度0%でも3D対象の辺を判別できる。
- 320px幅で横スクロールが発生しない。
- キーボードのフォーカスリングがガラス面の上でも明瞭に見える。
- タッチ操作で擬似ホバーによる移動が発生しない。
- 練習中、背景装飾より対象、残り時間、進行操作が先に見える。
