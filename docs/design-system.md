# HakoDraw デザイン方針

更新日：2026-09-13

## コンセプト

HakoDrawは「光のある静かなアトリエ」と「透明な製図器具」をモチーフにする。ガラスは装飾ではなく道具の素材として限定的に使い、練習対象とユーザーの線を常に最も明瞭に表示する。

## 画面の階層

1. 観察面・描画面：最も強いコントラストを持つ不透明な製図面
2. 進行操作：開始、一時停止、前後移動、残り時間
3. 練習条件：対象、軸、問題数、秒数
4. 調整項目：構図、焦点距離、補助表示、面

外枠、モード選択、設定面には半透明素材を使う。3Dビューと描画キャンバスには背景ぼかしを重ねない。暖色テーマは朝のアトリエ、暗色テーマは夜の作業机をイメージする。

## UI基盤

- 高度な選択部品が必要になった場合はBase UIを第一候補とし、通常CSSで外観を定義する。
- 予定された短い動きはCSSで実装する。
- 割り込み可能なジェスチャーや動的な移動が必要な場合だけMotionを検討する。
- Rare UIなどの装飾部品は、開始前または完了演出で一箇所ずつ検証する。
- アイコンはLucide Reactを継続する。

## 視覚トークン

- 背景：低彩度の暖色または寒色グラデーションと薄い製図グリッド
- ガラス：半透明面、明るい上端、細い境界、柔らかな影
- 製図面：高い不透明度、弱い内側の光、明瞭な輪郭
- 角丸：外枠26px、主要パネル16〜18px、操作部品12px
- アクセント：ライトは琥珀色、ダークは青緑色
- 軸色：X赤、Y緑、Z青を維持する

## 動き

- 頻繁な操作には装飾的な移動を加えない。
- 押下は120〜140msの`scale(.97)`で入力を受け取ったことを伝える。
- 登場には`cubic-bezier(.23,1,.32,1)`を使い、UIの遷移は300ms以内にする。
- ホバーによる変形はマウスなどの精密ポインターに限定する。
- `prefers-reduced-motion`では位置と変形の動きを停止する。
- 完了演出は頻度が低いため、現在の小さな祝福表現を許容する。

## 確認基準

- ライト・ダークの両テーマで本文と操作ラベルが読める。
- 面の不透明度0%でも3D対象の辺を判別できる。
- 320px幅で横スクロールが発生しない。
- キーボードのフォーカスリングがガラス面の上でも明瞭に見える。
- タッチ操作で擬似ホバーによる移動が発生しない。
- 練習中、背景装飾より対象、残り時間、進行操作が先に見える。
