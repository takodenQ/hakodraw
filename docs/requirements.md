# HakoDraw 初版要件・実装基準

更新日：2026-09-06。合意済み要件と、初版を動かすための実装値をまとめた文書。

## 目的と範囲

同じ形を多方向から描く時間制限付きクロッキーを通して、空間・立体の見え方を学ぶ。子どもにも大人の初心者にも親しみやすい表示とし、紙や別の描画ソフトに描く。

初版は正方形の面。Vite＋React＋TypeScript＋Three.jsでブラウザ内に完結する。認証・API・DB・アプリ内描画・外部モデル読み込みは対象外。公開先はVercelを候補とし、GitHubリポジトリは登録準備中。

2026-09-07確認：独自ドメイン `hakodraw.com` はXserverで取得済み。ホスティングへの接続・DNS設定は未実施。

## 回転練習

- 初期値は12問・30秒・Y軸。初期姿勢は正面。
- N問のi問目は `(i−1)×360°/N`。0〜330°の12問なら30°刻み。360°の重複は出題しない。
- 対称な形や線に見える角度も除外しない。
- カメラ固定、対象を選択したグローバル軸の正方向へ回転する。
- 自動進行・次へは次の角度へ、前へは逆方向へ0.5秒で滑らかに回転する。
- 回転終了後に、その問題の制限時間を確保する。標準は描画6分＋回転約5.5秒。
- 問題数1〜360、秒数1〜3600の整数を初版の実装範囲とし、不正値は説明して開始を無効にする。

## 座標系・描画

- Three.js標準の右手系・Y-up。正方形はXY平面、原点中心、辺長2。
- カメラは+Z側、距離5.5。透視投影、焦点距離50mm、filmGauge既定35、aspect比1を再現基準とする。写真の50mmと同一の画角を保証する値ではない。
- 表面は明るい中性色、裏面は少し暗い薄赤色。辺は明確に表示する。
- ライト、地面、陰影、材質選択は将来拡張とし、初版はフラットな面色。
- 開始前から対象をプレビューし、開始時に表示枠の位置や大きさを変えない。
- 表示枠は常に正方形。グリッドは画面に固定する。

## ビューの表示設定

- 初期状態で閉じた「ビューの表示設定」に、グリッドとローカル軸の設定をまとめる。項目間の区切り線は設けない。
- グリッドの選択肢は非表示→2×2→3×3→4×4。初期値4×4。
- グローバル軸表示は設けない。対象原点のローカル軸が対象と共に回転する。
- 初期姿勢ではローカル軸とグローバル軸を一致させる。X赤・Y緑・Z青に文字を添える。
- 開始前の回転軸は三つのラジオボタン。軸色・文字・方向説明・チェック・枠で対応を示し、選択時は対象の軸を短く強調する。
- 「練習中のローカル軸」はON/OFFスイッチ、初期値ON。開始前はOFFでも表示し、練習中と停止中は設定に従う。設定画面へ戻ると再表示する。
- 表示設定の変更・開閉では問題、角度、時間、停止状態をリセットしない。

## 操作と中断

| 操作・状態 | 動作 |
|---|---|
| 開始 | 準備カウントダウンなしで1問目を開始 |
| 前へ・次へ | 対応角度へ回転し、制限時間を設定値に戻す |
| 最初の問題の前へ | 無効 |
| 最後の問題の次へ／時間切れ | 完了 |
| 一時停止／再開 | 残り時間を保持／続きから計時 |
| 停止中の前後移動 | 回転後も停止 |
| 回転中 | 前後移動と一時停止は無効。終了は可能 |
| 途中終了 | 回転や演出をキャンセルし、設定へ戻る |
| タブ非表示 | 自動停止。回転途中なら目的角度へ着地して停止 |
| 画面サイズ・向き変更 | 進行を保持 |
| ページ更新 | 設定だけ復元し、セッションは開始前へ戻す |

時間はフレーム数でなく単調時計の期限で計算する。回転後のフレームが遅れても次の問題の時間を省略しない。WebGL初期化失敗・コンテキスト喪失時は説明し、開始／進行を停止して再読み込みを案内する。

## タイマー・完了演出

- ビュー外に十分な余白を取り、問題番号・残り秒数・横バーを表示する。
- バーは右端から左へ減る。残り10秒以下は赤くせず、不透明度1→0→1を1秒周期で繰り返す。数字は点滅しない。
- 停止時は時間と点滅を止める。
- 完了時は補助表示を隠し、同じ対象が軽く跳ねて回り、紙吹雪と「セッション完了！」「今日の練習、おつかれさま！」を表示する。
- 約2秒で静止し、顔・音・ループは付けない。途中終了では祝わない。
- 演出中から同じ設定で再スタート／設定へ戻る操作が可能。
- スキップできるため、描いた枚数や上達は断定しない。
- 端末の動きを減らす設定では、回転・点滅・紙吹雪の動きを省き、静止結果を表示する。

## 配色・保存・画面サイズ

- ライトは暖色ホワイト＋優しいオレンジ、ダークはニュートラルな暗色＋淡い青緑。
- 太陽／月の単一ボタンで現在の配色を示し、押すたび切り替える。読み上げ名は次の動作を示す。
- 初回は端末配色に追従し、手動選択後は保存した設定を優先する。
- 問題数・秒数・軸・グリッド・ローカル軸・配色をバージョン付きキーでlocalStorageに保存。
- 破損・不正データは初期値へ補正。保存不可でも練習を続けられるようにし、その旨を表示する。
- 縦持ちは上下、広い画面と低い横持ちは左右配置。主な操作は44px以上、入力文字16px、通常ラベル14pxを目安とする。
- 初版の確認サイズは320×640、390×844、844×390、1280×900。キーボードとフォーカス表示を確認する。

## 確認と将来構想

単体テストで進行・時間・回転・停止・中断・保存データ補正を確認する。ブラウザで実際の描画、設定、保存と再読み込み、配色、入力エラー、保存不可、完了と再開、動きを減らす設定、各画面サイズを確認する。実機スマホと長時間使用は別途評価する。

今後は円、基本立体、複合形状、人体、配置練習、光・陰影へ拡張する。外部モデルはGLBを第一候補とし、形と元の材質、向き・原点・サイズ補正のお題定義、表示プリセットを分離する。人体と補助形状は共通の回転ルートで管理する。写真からのポーズ生成、ユーザー自身のモデル読み込みは将来候補。

## 基本図形の追加

- 対象は正方形・円・立方体・直方体。開始前の4択ラジオボタンで選択し、プレビューを即時更新する。練習中は変更しない。
- 選択は既存の設定キーに保存。旧設定・不正な形IDは正方形に補正する。
- 全対象で原点・初期ローカル軸を統一。円はXY平面・半径1、立方体は辺長2、直方体はX=1.4、Y=2.2、Z=1。
- カメラ固定、面色と輪郭を共通化し、陰影は追加しない。円は外周のみを表示し、内部の三角分割線を出さない。立体の隠れた辺は表示しない。

## 人体・視点・面表示の拡張（基本図形版の表示仕様を更新）

- 頭・胸郭・骨盤の3つの直方体による人体を追加。ユーザー提供画像の比率・傾き・ひねりを参考にした近似で、囲むボックスや手足は含めない。元Blenderデータの復元ではない。
- 視点の高さは開始前に−60°〜60°で設定、初期値20°の見下ろし。距離5.5と注視点は固定し、セッション中は変更しない。
- ビューの表示設定に面の不透明度0〜100%（初期65%）、面の明度0〜100%（初期75%）を追加。練習中も変更可能で進行を保持。
- 全対象で奥の辺を薄く、手前の辺を濃く表示。不透明度0%でも深度判定を保持し、辺のみ表示する。半透明面は最前面を描き、奥の面の重ね塗りはしない。
- 追加設定は同じ保存キーで保存し、旧設定では初期値を補う。

## 初期姿勢・焦点距離（2026-09-08）

視点の高さを廃止し、開始前に原点中心の一様スケール50〜150%、XYZ初期回転各−180〜180°、焦点距離35〜150mmを指定する。初期値100%・各0°・50mm。初期姿勢はThree.jsのXYZ Eulerで定義し、その外側から選択したワールド軸のセッション回転を適用する。対象とローカル軸を一緒に拡大縮小・回転する。

カメラは+Z側から原点を向く。filmGauge=35、距離=5.5×焦点距離/50で連動させ、原点の投影倍率を保ちつつ遠近感を変える。拡大時は枠外にはみ出す場合がある。設定は保存し、セッション中は固定。旧elevationは符号を逆にしたX初期回転へ移行する（初期の見え方を近づける移行で、以前の回転軌道とは異なる）。リセットは姿勢・スケール・焦点距離のみを既定値へ戻す。

画面位置調整：初期姿勢とパースに左右・上下各−100〜100%を追加。0%は画面中央、+Xは右、+Yは上。100%は原点の深さで画面半幅／半高（1.925ワールド単位）分の移動を表す。Z位置は0固定。移動はスケール・初期姿勢・セッション回転の外側に適用し、対象がその位置で回転する。設定保存・一括リセット対象に含む。端へ寄せると対象は枠外にはみ出す場合がある。

セッション中の構図調整：左右・上下位置と大きさを「ビューの表示設定」へ移動し、開始前・練習中・一時停止中に同じUIで変更可能とする。位置と大きさ専用のリセットを追加。変更とリセットは問題・回転角度・残り時間・停止状態を変更しない。初期XYZ回転と焦点距離は引き続き開始前のみ変更できる。

## 中央配置と設定整理

全画面幅でヘッダー→正方形ビュー→設定の一列配置とする。開始前の常時表示は形、回転軸、問題数、秒数、スタートボタンのみ。開始見出し・説明・所要時間の要約は削除する。その他はスタート下の「ビューの設定」に集約して初期状態は閉じる。内部は初期姿勢とパース、位置と大きさ、補助表示と面で整理。開始時・設定へ戻る時にも折りたたむ。練習中の位置・大きさ・補助表示変更は維持する。

## ビューの直接操作

姿勢・位置・スケールのスライダーを廃止。開始前は左ドラッグ／1本指で仮想トラックボール回転、右ドラッグ／2本指の中心移動で平面移動、ホイール／ピンチで対象のスケール変更。焦点距離は変更しない。練習中は回転をロックし、移動と拡縮のみ可能。ビュー内のタッチは対象操作、外側はページスクロール。＋／−とリセットボタン、矢印キー移動、Shift＋矢印で初期回転、＋／−キーで拡縮を提供する。ポインターキャンセル・キャプチャ喪失時に接触情報を解放。タッチはブラウザエミュレーションで確認済み、実機の操作感は別途確認する。

## 段階操作への変更（2026-09-09）

上記の直接操作を廃止し、ビュー直下に回転・移動・大きさの切替パネルを配置する。回転は選択したXYZ初期角度を15°刻みのボタンと単一スライダーで調整し、選択軸を0°へ戻せる。初期姿勢のXYZ Euler規約は維持する。移動は画面方向の十字ボタンで5%刻み、中央復帰を提供する。大きさは10ポイント刻み、100%復帰を提供する。細かく操作する場合は1°または1%刻みへ切り替える。練習中は回転を無効化し、移動・大きさのみ操作できる。設定保存と進行状態保持は維持する。ビュー上のドラッグ・ホイール・ピンチによる対象操作は行わず、タッチのページスクロールを妨げない。
