# パース練習

更新日：2026-09-29

## 目的と範囲

「ランダムに向きが変わる立方体を、パース線をなぞって描く」ことだけに特化した練習。立体の種類は立方体1個のみで、選択肢は設けない（複数の立体はパース線が複雑になり、目的がぼやけるため2026-09-29に廃止した）。

## 画面

- 練習モードのタブは、ホーム・回転練習・接続練習・**パース練習**の順で、パース練習を最も右に置く。
- 12問・30秒を初期値にし、左右の同サイズ正方形にお手本と描画領域を配置する。スマートフォンも横並びのため、細かい描画には横向きや大きい画面が向く。

## 出題

- Three.jsの透視投影で立方体の頂点を計算し、同一座標からお手本・正解・各辺を画面端まで延長したガイドをSVGで描く。
- 問題ごとに、次の2つをランダムに変える。
  - 立方体のY回転（向き）。前の問題から60°〜300°回す（似た向きが続かない）。
  - 目線の高さ（カメラの仰角8°〜38°）。アイレベルの位置と、上面の見え方が変わる。
- 乱数の種は練習を開始する（または設定へ戻る・もう一度開始する）たびに新しくする。同じ練習の中では、前後へ移動しても同じ問題は同じ形で再現される。
- 立方体は常に画面内に収まる。アイレベルは、カメラから水平方向へ無限に遠い点の投影で求める水平消失線で、水平な辺の消失点はこの線上に乗る。
- X/Y/Z方向を色分けした補助線を、濃さ0〜50%（初期18%）で調整できる。

## 描画と進行

- マウス・ペン・指の自由描画。線への吸着なし。
- 一筆戻す、全消去、答えの重ね合わせ、前後移動、一時停止に対応。答え合わせは自動停止する。
- 描画できるのは進行中のみ。各問題の線はセッション内で保持し、再開始でクリアする。
- 時間切れは次の問題へ即時遷移し、全問終了で完了。タブを隠すと停止する。
- 練習の記録・切り替え音・キー操作（スペース、←→）は、他のモードと共通（`beginner-support.md`）。

## 対象外

複数の立体、立方体以外の形、採点、描画履歴の永続保存。
