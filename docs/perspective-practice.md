# パース練習の試作

ヘッダー下の練習モードから選択。初版は立方体1個、12問・30秒を初期値にし、左右の同サイズ正方形にお手本と描画領域を配置する。スマートフォンも横並びのため、細かい描画には横向きや大きい画面が向く。

Three.jsの透視投影で立方体の頂点を計算し、同一座標からお手本・正解・各辺を画面端まで延長したガイドをSVGで描く。カメラは固定で、問題ごとに立方体のY回転を変更する。アイレベルは同じカメラの水平消失線。X/Y/Z方向を色分けし、濃さ0〜50%（初期18%）で調整可能。

マウス・ペン・指の自由描画。線への吸着なし。一筆戻す、全消去、答えの重ね合わせ、前後移動、一時停止に対応。答え合わせは自動停止。描画できるのは進行中のみ。各問題の線はセッション内で保持し、再開始でクリア。時間切れは次の問題へ即時遷移、全問終了で完了。タブを隠すと停止する。

2個以上の立体、採点、描画履歴の永続保存はこの試作の対象外。
