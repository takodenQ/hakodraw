# 全身素体（試作）

ユーザー提供の正面・側面・背面の三面図を参考にした、腕を開いた静止姿勢の簡略モデル。画像を直接3D変換したものではなく、断面の幅と前後の厚みを手作業で近似したモデルです。医学・解剖学上の正確性を検証した教材モデルではありません。

`src/scene/mannequin.ts` の BODY_PARTS で各パーツの位置・回転・断面を調整できます。断面は `[高さ, 半幅, 前方の厚み, 後方の厚み]`。Yが上、+Zが正面。左右の四肢は対称生成します。元の身長は約7.5単位で、ビューでは全身の中央を原点に配置します。

頭・耳・首・胸郭・胸部・腹部・骨盤・肩・上腕・肘・前腕・手首・掌・指・大腿・膝・下腿・足首・足を分離。関節と腹部は暗くし、断面線で前後関係を補助します。既存の回転セッション、透過、明度、構図調整に対応します。関節のポーズ編集、リギング、GLB書き出しはこの試作には含みません。
