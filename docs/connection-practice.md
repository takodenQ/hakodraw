# 接続練習モード 要件定義

更新日：2026-09-12

## 1. 目的

人体を一度に全身として模写するのではなく、2〜3個の単純化された立体の接続関係に分け、さまざまな方向から描くことで、立体的な人体を組み立てる能力を身につける。

本モードでは、画面上の二次元的な位置の暗記ではなく、次の関係を三次元的に理解することを重視する。

- 親パーツに対する子パーツの接続位置
- 各パーツの向きと傾き
- パーツ間の距離、長さ、比率
- 重なりと前後関係
- 接続部から次のパーツが伸びる方向

練習は「単体 → 2〜3パーツの接続 → 部分人体 → 全身」の段階へ将来拡張できる構造とする。初版は2〜3パーツの接続練習に限定する。

## 2. 学習上の基本方針

### 2.1 共通パーツを介した学習

「頭＋胸郭」と「胸郭＋両肩」のように、共通する親パーツを持つ練習項目を組み合わせる。胸郭などの共通パーツを基準に、別々に学習した接続関係を後から統合できる構成とする。

### 2.2 観察と想起を分ける

お題を見ながら描く時間と、描画後に正解や補助情報を確認する時間を分ける。正解の補助線を常時表示して写すだけの練習にはしない。

### 2.3 局所練習だけで完結させない

初版では部分接続のみを扱うが、データ構造と画面遷移は、複数の接続を統合した部分人体・全身問題を将来追加できるようにする。

## 3. 用語

| 用語 | 定義 |
|---|---|
| パーツ | 頭、胸郭、骨盤、肩関節、上腕などを単純化した立体 |
| 親パーツ | 接続位置や向きを判断する基準となるパーツ |
| 子パーツ | 親パーツに接続されるパーツ |
| 接続項目 | 2〜3パーツで構成される練習対象 |
| 接続点 | 関節中心など、パーツ同士の接続基準となる点 |
| 接続面 | 子パーツが付く位置と向きを示す親パーツ上の面 |
| 基準姿勢 | 接続項目に定義されたパーツ同士の初期配置 |
| 視点変化 | 接続関係を変えず、対象全体を回転して見る方向を変えること |
| 配置変化 | 関節角度など、パーツ同士の接続関係自体を変えること |

## 4. 初版の対象範囲

### 4.1 初版に含める接続項目

以下を初期プリセットとする。

1. 頭＋首＋胸郭
2. 胸郭＋左右の肩関節
3. 片側の肩関節＋上腕
4. 胸郭＋骨盤
5. 骨盤＋左右の大腿
6. 片側の大腿＋下腿

左右差のない片側項目は、右側を基準データとして持ち、左右反転して出題できる構造とする。ただし初版の画面では右側のみの出題でもよい。

### 4.2 初版に含めないもの

- 自由なポーズ編集
- 関節角度のランダム変更
- 部分人体および全身の統合問題
- 自動画像認識による採点
- 手、足、顔、筋肉、衣服、髪の詳細
- ユーザーによる接続項目の作成
- 練習履歴のアカウント同期
- 医学・解剖学的な正確性の保証

## 5. 練習モードの入口

既存の練習モード選択に「接続練習」を追加する。

接続練習の開始前画面では、次を設定できる。

- 接続項目
- 回転軸：X、Y、Z
- 問題数：1〜360
- 1問の秒数：1〜3600秒
- 表示する補助情報
- 初期姿勢
- 焦点距離
- 対象の位置と大きさ

問題数、秒数、回転軸、ビュー設定の操作規則は、可能な範囲で既存の回転練習と共通化する。

## 6. 出題仕様

### 6.1 初版の出題方式

初版では、選択した一つの接続項目を基準姿勢のまま全体回転させる。パーツ同士の相対位置と相対回転は問題間で変更しない。

N問のi問目の回転角度は、既存の回転練習と同じく次で求める。

`(i - 1) × 360° / N`

360°と重複する角度は出題しない。対象は選択したワールド軸の正方向へ回転する。

### 6.2 出題中の表示

- 対象は画面中央を基準に表示する。
- 全パーツは同一の透視投影下で描画する。
- 手前の辺を濃く、奥の辺を薄く表示する。
- パーツの重なりと深度判定を維持する。
- 選択した補助情報は対象と共に回転する。
- 問題間の回転中は制限時間を消費しない。

### 6.3 将来の配置変化

関節角度を変える出題は、全体の視点回転と区別して将来追加する。配置変化を追加する場合も、接続点が外れたり、人体として成立しない範囲へ無制限に回転したりしないよう、接続項目ごとに可動範囲と生成規則を定義する。

## 7. 練習対象の表現

### 7.1 パーツ形状

パーツは、箱、楕円体、球、円柱、台形状の立体など、向きと厚みを読み取りやすい単純形状で表現する。

完全な球体のように向きを判別できない形状には、軸線または断面線を付ける。肩関節の球は、上腕の方向を判断するための接続点と軸を持つ。

### 7.2 必須の補助情報

初版では、次の表示を個別またはプリセットで切り替えられるようにする。

- パーツの輪郭と奥の辺
- パーツ中心線
- 接続点
- 接続軸
- 左右、上、前を判断するための方向線

接続面の面塗り表示は推奨機能とし、実装負荷が高い場合は接続点と接続軸で代替できる。

### 7.3 補助表示プリセット

最低限、次の3段階を用意する。

| プリセット | 表示内容 |
|---|---|
| 学習 | 中心線、接続点、接続軸、方向線を表示 |
| 標準 | 中心線と接続点を表示 |
| テスト | 立体の輪郭と奥の辺のみ表示 |

初期値は「標準」とする。セッション中の変更は、問題番号、角度、残り時間、一時停止状態を変更しない。

## 8. 練習進行

状態遷移は既存の回転練習を基準とする。

`setup → running → rotating → running → … → complete`

- 開始すると1問目を表示し、制限時間を開始する。
- 時間切れまたは「次へ」で次の角度へ進む。
- 「前へ」で前の角度へ戻る。
- 回転終了後にその問題の制限時間を全て確保する。
- 一時停止中は残り時間を保持する。
- タブ非表示時は自動停止する。
- 途中終了では完了演出を行わない。
- 最終問題の終了後はセッション完了とする。

描画は紙または別の描画ソフトを併用することを初版の基本とする。アプリ内描画と正解重ね合わせは後続段階で追加できる。

## 9. 答え合わせと自己評価

### 9.1 初版

初版では、各問題で補助表示を切り替え、輪郭だけで観察した後に中心線・接続点・接続軸を確認できることを答え合わせとする。

補助情報を表示しても、タイマーおよび問題の進行状態は保持する。

### 9.2 推奨する次期機能

パース練習の描画領域を再利用または共通化し、ユーザーの線と正解を重ね合わせる。

答え合わせ後に、任意で次の自己評価を記録できるようにする。

- 向き
- 接続位置
- 長さ・比率
- 奥行き・重なり
- ほぼ描けた

自己評価を追加しても、「正解率」や「上達」を自動的に断定しない。将来は評価結果をもとに苦手な接続項目を多めに出題できるようにする。

## 10. データ要件

接続項目は、画面やレンダラーに直接固定せず、定義データとして追加可能にする。各接続項目は概念上、少なくとも次を持つ。

- 一意なID
- 表示名
- 学習目的の説明
- 構成パーツ
- 親子関係
- 各パーツの形状、寸法、位置、回転
- 接続点の位置
- 接続軸の方向
- 中心線および方向線
- 対象全体の原点と表示用境界
- 推奨カメラ設定
- 左右反転の可否
- 将来用の関節可動範囲

パーツ定義と接続項目定義を分離し、同じ胸郭や肩関節を複数の練習項目で再利用できるようにする。

## 11. 保存要件

次の設定をブラウザへ保存する。

- 最後に選択した接続項目
- 問題数と秒数
- 回転軸
- 補助表示プリセットまたは各表示設定
- 面の不透明度と明度
- 対象の位置と大きさ
- 初期姿勢と焦点距離

保存データにはバージョンを持たせる。不足項目は既定値で補い、不正な接続項目IDは最初の有効なプリセットへ補正する。保存できない場合も練習は継続可能とする。

## 12. UI・アクセシビリティ要件

- 既存モードと共通する操作名、配置、配色を使用する。
- 主な操作領域は44px以上を目安とする。
- 色だけでパーツ、軸、接続点を区別しない。
- 補助線はライト・ダーク両テーマで判別できるコントラストを持つ。
- 動きを減らす設定では問題間の回転アニメーションを省略し、目標角度を即時表示する。
- スマートフォン縦持ちでも対象と主要操作が利用できる。
- キーボード操作と明確なフォーカス表示を提供する。

## 13. 完了条件

初版は、次を満たしたとき完成とする。

1. 6種類の接続項目から一つを選んで開始できる。
2. 各接続項目が2〜3個の立体として正しい親子配置で表示される。
3. X、Y、Zのいずれかを選び、指定問題数に分割した角度で練習できる。
4. 中心線、接続点、接続軸を含む補助表示を切り替えられる。
5. 補助表示を変更しても練習状態が失われない。
6. 前後移動、一時停止、途中終了、タブ非表示時の自動停止が既存仕様どおり動作する。
7. 奥行き、半透明、奥の辺、焦点距離、位置、大きさが既存の3D表示設定と整合する。
8. 設定が保存され、旧データや破損データから安全に復元できる。
9. 320×640、390×844、844×390、1280×900で主要操作が利用できる。

## 14. テスト観点

### 14.1 単体テスト

- 接続項目IDの検証と補正
- パーツの親子変換
- 全体回転後もパーツ間の相対変換が変わらないこと
- 左右反転時の位置と向き
- 問題番号と回転角度の算出
- 補助表示変更時のセッション状態保持
- 保存データの移行と既定値補完

### 14.2 表示・操作テスト

- 各方向から接続位置とパーツの向きを判別できること
- 完全な球体でも接続軸によって方向を判断できること
- 前後の辺と重なりが破綻しないこと
- 半透明0%および100%で補助線が利用できること
- ライト・ダークテーマで補助表示が判別できること
- 前へ、次へ、一時停止、途中終了、完了が既存仕様と一致すること
- スマートフォンで設定変更とページスクロールを行えること

## 15. 将来拡張の優先順位

1. アプリ内描画と正解重ね合わせ
2. 自己評価と苦手項目の再出題
3. 関節角度を変更する配置練習
4. 接続範囲を増やす段階コース
5. 部分人体と全身の統合問題
6. 頭身、肩幅、手足の長さなどの体型変更
7. 丸型、角型、三角型などの形状言語プリセット

配置練習を追加する際は、視点変化と配置変化を別々に練習できる設定を残す。両者を最初から同時にランダム化して、誤りの原因を判別できなくしない。

## 16. 非機能上の方針

- 接続項目を追加してもセッション進行ロジックの分岐が増えすぎない構成とする。
- 既存の人体モデルとは形状定義を可能な範囲で共有するが、全身モデルの表示都合を接続練習の学習表現より優先しない。
- 初版の対象データはアプリ内に同梱し、通信なしで利用できる。
- 外部モデルや生成AIを初版の必須要件にしない。
- 本機能は作画練習を支援するもので、学習効果や人体構造の医学的正確性を保証しない。
