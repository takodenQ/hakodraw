# 接続練習モード 要件定義

更新日：2026-10-10（三面図の人体モデルとランダムな曲げ・ひねり・向きに作り直し）

## 1. 目的

全身を一度に模写するのではなく、人体をいくつかのパーツの「つながり」に分けて、部分ごとの立体構造を確かめながら描く。次の関係を三次元的に理解することを重視する。

- 親パーツに対する子パーツの接続位置（関節の位置）
- 関節の曲げとひねりによる、パーツの向きの変化
- パーツ間の長さ・太さ・奥行きの比率
- 重なりと前後関係

## 2. 人体モデル

ユーザー提供の三面図「HakoDraw人体図形モデル3面図」（正面・側面・背面、関節ピボット付き）を、そのまま3Dモデルにした（`src/body.ts`）。

- 単位：1頭身 = 100。身長は7.5頭身 = 750。
- 座標：足裏が Y=0、Yが上、+Zが正面、−Xが人物の右側。正面図の x → X、上からの y → Y（750 − y）、側面図の x（つま先側が +）→ Z。
- 形：各パーツは、正面図と側面図の上下の辺から作った「上下2つの断面をつないだ台形の箱」。胸郭（上が約9°後傾）・腹部・骨盤（約7°前傾）・腕の傾きは側面図・正面図のとおり。肩・肘・膝は球。足は側面図の輪郭を左右に押し出した形。手は手のひら・指・親指の3つ。
- 目印：頭の高さ中央の線、頭・胸郭・腹部・腰の前後の中心線、指の付け根の線は、三面図と同じく常に表示する。
- 右側を三面図から写し、左側は左右反転で作る。
- 関節のピボットは三面図のオレンジの点（正面図と側面図の高さの平均）を使う。

## 3. 練習の組み合わせ

| 項目 | パーツ（先頭が土台） | 動く関節 |
|---|---|---|
| 頭・首・胸郭 | 胸郭 → 首 → 頭 | 頸椎、頭の付け根 |
| 胸郭・肩・上腕 | 胸郭 → 左右の肩（固定）→ 左右の上腕 | 左右の肩関節 |
| 上腕・肘・前腕・手 | 右上腕 → 肘（固定）→ 右前腕 → 右手 | 肘関節、手関節 |
| 胸郭・腹部・腰 | 腰 → 腹部 → 胸郭 | 腰椎、胸椎 |
| 腰・太もも | 腰 → 左右の太もも | 左右の股関節 |
| 太もも・膝・ふくらはぎ・足 | 右太もも → 膝（固定）→ 右ふくらはぎ → 右足 | 膝関節、足関節 |

以前の項目ID（`head-chest` など）は、保存済みの設定とコースの進み具合のため、近い新しい項目へ読み替える。

## 4. 出題

- 問題ごとに、各関節を下の範囲の中でランダムに曲げ・ひねる。
- さらに全体をランダムな向きで出題する：左右はどこからでも（0〜360°）、上下 ±60°、傾き ±40°。
- 乱数の種は練習を開始するたびに新しくする。同じ練習の中では、前へ戻ると同じポーズ・向きを再現する。
- 問題が変わるときは、表示中のポーズから新しいポーズへ約0.5秒で移る（動きを減らす設定では即時）。この間は制限時間を消費しない。
- 練習前のプレビューは、基準姿勢を少し斜め上から見た向き。
- どのポーズ・向きでも枠に収まるよう、多数のポーズを試して最も広がる距離から大きさを決める。
- 向きはランダムなので、回転軸の選択と「オブジェクトの調整」の初期回転は出さない（移動と大きさは使える）。

### 4.1 関節の可動域（度）

一般的な関節可動域（日本整形外科学会などの参考可動域）の中から、描画練習で自然に見えるよう狭めた範囲。右側で定義し、左側は反転する。医学的な正確さを保証するものではない。

| 関節 | 前後（x） | 左右（z） | ひねり |
|---|---|---|---|
| 頸椎 | 前屈30 / 後屈10 | 側屈 ±20 | 回旋 ±30 |
| 頭の付け根 | うなずき20 / 後ろへ15 | 傾げ ±10 | 回旋 ±40 |
| 胸椎 | 前屈25 / 後屈10 | 側屈 ±15 | 回旋 ±25 |
| 腰椎 | 前屈30 / 後屈15 | 側屈 ±15 | 回旋 ±10 |
| 肩関節 | 屈曲120 / 伸展30 | 外転100 / 内転10 | 内旋40 / 外旋60 |
| 肘関節 | 屈曲0〜140（前にだけ曲がる） | — | 回内・回外 ±80 |
| 手関節 | 橈屈20 / 尺屈30 | 掌屈70 / 背屈60 | — |
| 股関節 | 屈曲100 / 伸展20 | 外転40 / 内転15 | 内旋・外旋 ±35 |
| 膝関節 | 屈曲0〜130（後ろにだけ曲がる） | — | 回旋 ±10 |
| 足関節 | 底屈45 / 背屈20 | 内返し20 / 外返し15 | ±10 |

回転は、骨の向きを軸にしたひねり → 前後 → 左右の順に、親パーツの向きで重ねる。

## 5. 補助表示

| プリセット | 表示内容 |
|---|---|
| 学習 | 中心線、接続点、関節の軸（骨の向き・肘と膝の曲がる軸）、左右の線と正面の矢印、ローカル軸 |
| 標準（初期値） | 中心線、接続点 |
| テスト | 立体の輪郭と奥の辺のみ |

補助表示はパーツと一緒に曲がり、回る。練習中に変えても、問題番号・残り時間・一時停止は変わらない。

## 6. 練習の進行と保存

進行（開始、前へ・次へ、一時停止、途中終了、タブ非表示時の自動停止、完了）は回転練習と同じ。保存するのは、最後に選んだ項目、補助表示、問題数・秒数、面の不透明度・明度、位置と大きさ。

## 7. 対象外（将来候補）

- 自分でポーズを作る、左右を入れ替えて出題する
- 部分人体・全身の統合問題（モデルは全身分あるので組み合わせの追加で対応できる）
- 関節どうしの組み合わせの制約（例：肩を大きく屈曲したときの外転の制限）、パーツどうしのめり込みの判定
- 採点

## 8. テスト

- 単体：`body.test.ts`（三面図の寸法と傾き、左右反転、関節の位置、曲がる向きの解剖学的な正しさ、可動域内のランダム、再現性）、`connections.test.ts`（項目、ID の読み替え、組み立て、関節での曲げ、枠に収まること）
- E2E：`tests/connection.spec.ts`（6項目の表示、補助表示、一時停止中の移動、保存、問題ごとのポーズ・向きの変化と再現、画面サイズ）
