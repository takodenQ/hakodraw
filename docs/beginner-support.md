# 初心者向け・継続支援 要件定義

更新日：2026-09-29

## 1. 目的

イラスト初心者が迷わず最初の一歩を踏み出し、無理なく練習を続けられるようにする。既存の練習（回転・パース・接続）は変更せず、その手前と後ろに「始めやすさ」と「続けやすさ」を足す。

「上達」や「うまさ」は判定しない。記録するのは「練習した日・回数・時間」だけとする（回転練習の要件にある「描いた枚数や上達は断定しない」を、全モードに広げる）。

## 2. 洗い出した課題

| 課題 | 対応 |
|---|---|
| 最初の画面が設定項目の羅列で、何をすればよいか分からない | ホーム画面を追加。初回は3ステップの説明と「今日のおすすめ」を表示する |
| 「回転軸」「焦点距離」など専門用語が多い | 軸の説明文を追加。焦点距離などは従来どおり「ビューの設定」に折りたたむ |
| 問題数（1〜360）・秒数（〜3600）を自分で決める必要がある | 「おためし／ふつう／じっくり」のプリセットと、全体の所要時間の表示を追加 |
| 何から練習すべきか分からない | 「はじめてのコース」（12ステップ）を追加し、次のおすすめを提示する |
| 練習の記録がなく、続けている実感が得られない | 練習記録・週の目標・カレンダー・スタンプを追加 |
| 練習後に何も残らない | 完了後に感想（むずかしい／ちょうどよい／もの足りない）を選べる。次のおすすめの量へ反映する |
| 紙を見ている間は画面の切り替えに気づけない | 切り替え音（既定でON、切り替え可）を追加 |
| 練習中に画面が暗くなる | 練習中は画面を消灯させない（Screen Wake Lock。未対応の端末では何もしない） |
| 片手で紙を押さえていると操作しづらい | スペース（一時停止・再開）、←→（前後）のキー操作を追加 |
| 再読み込みや戻るボタンでホームへ戻される | 画面をURLのハッシュ（`#rotation` など）と同期する |
| 実装の不要物・重複 | 英語の装飾ラベル「OBSERVATION」を削除。`Settings` の二重宣言を統合 |

## 3. ホーム画面

- 「ホーム」を練習モード選択の先頭に追加し、起動時の初期画面とする。
- **はじめての方へ**：記録が0件で、まだ閉じていない場合だけ表示する。紙と鉛筆を使うこと、観察が練習であることを伝える。「わかった」で閉じ、以後は表示しない。
- **今日のおすすめ**：コースの次のステップを、目的・問題数・秒数・所要時間つきで表示する。
  - 「はじめる」：該当する練習画面へ設定を入れた状態で移動する（開始は本人が押す）。
  - 「1分だけやってみる」：2問×30秒に絞る。続けることを優先する入口で、練習した日には数えるが、コースのステップは完了扱いにしない。
- **練習の記録**：今週の練習日数と週の目標（1〜7日、既定3日）、直近5週間のカレンダー、連続日数、合計回数・時間。
- **実績**：獲得数、最近のメダル、もうすぐ達成できる実績を表示し、実績画面（`#achievements`）を開ける。新しい実績があると「NEW」を表示する。
- **はじめてのコース**：12ステップの一覧。完了・おすすめの表示と、任意のステップの開始。
- **自由に練習する**：既存の3モードへの入口。
- **最近の練習**：直近6件。
- **記録の保存・引き継ぎ**：JSONの書き出し・読み込み・消去。

## 4. 練習記録と連続日数

- 記録は端末のブラウザ（localStorage、キー `hakodraw.progress.v1`）だけに保存し、外部へ送信しない。最大2000件（古いものから整理する。獲得した実績は別に保存し、整理されても消えない）。
- 1件の記録：日時、モード、名称、問題数、秒数、進んだ問題数、完了したか、コースのステップID、感想。
- **記録するタイミング**：セッションを完了したとき、または1問以上進んで途中終了したとき。開始してすぐ終了しただけの操作は記録しない。
- **練習した日**：その日に記録が1件以上ある日。
- **週**：月曜始まり。
- **連続日数**：1日までの休みは途切れない。最後の練習が一昨日以内なら継続中とする。途切れた場合も責めず、「今日が最初の1日です」と表示する。
- 読み込んだファイルや壊れた保存データは、使える項目だけを残して補正する。保存できない環境でも練習は続けられ、その旨を表示する。

## 5. はじめてのコース

正方形 → 円 → 立方体 → 直方体 → パース（立方体）→ 人体（3ブロック）→ 頭・首・胸郭 → 胸郭・肩・上腕 → 上腕・肘・前腕・手 → 胸郭・腹部・腰 → 腰・太もも → 太もも・膝・ふくらはぎ・足。

接続練習のステップは、2026-10-10 に三面図の人体モデルへ作り直した。ステップIDは以前のまま（`head-chest` など）にして、完了済みの進み具合を引き継ぐ。

- 各ステップは、既存モードの設定（形または接続、軸、問題数、秒数、補助表示）と、ねらい・描くコツを持つ。
- 完了したステップ（`completed` かつステップID付き）は再びおすすめしない。順序に関係なく、任意のステップを練習できる。
- 練習画面では、設定を変更してステップと合わなくなった場合はコースの案内と記録の紐づけを外す。
- **量の調整**：直近の感想が「むずかしかった」なら、1問の時間を約1.5倍にして問題を1つ減らす。「もの足りない」なら問題を2つ増やす。調整した理由を表示する。

## 6. 練習中の支援

- 切り替え音：問題が切り替わったとき、完了したときにやわらかい音を鳴らす（Web Audio。音声ファイルなし）。設定画面と練習中のどちらからでも切り替えられ、設定は保存する。
- 画面の消灯防止：練習中のみ。
- キー操作：スペース、←、→。ボタンや入力欄にフォーカスがあるときは通常の動作を優先する。
- コースの練習では、練習中も「描くコツ」を1行表示する。

## 7. 完了後

- 練習完了の見出しは従来どおり。今週の練習日数と目標、連続日数を伝える。
- 感想を任意で選べる。
- 「次のおすすめ」「同じ設定でもう一度」「設定に戻る」「ホームへ」を提示する。

## 8. 実績（メダル）

続けたこと・やってみたことを称えるための実績。上達や巧拙は判定しない。ゲームの実績のように、メダルを集める楽しみで継続を後押しする。

- **計算**：練習記録だけから求める（`achievements.ts`）。1問＝1こ（描いた数）と数える。
- **種類**（4分類・58個）：
  - 練習の量：練習回数（1・10・50・100・300・1000）、描いた数（10・100・500・1000・3000・10000）、練習時間（30分〜50時間）。
  - つづける：練習した日数（3〜365日）、連続日数（3〜100日、お休み1日まで可）、週3日以上練習した週（1〜52週）、毎日練習した週、1週間以上あいたあとの再開（「おかえりなさい」）。
  - ひろげる：はじめてのコースの進み具合、練習の種類数（最大17：回転6・接続10・パース1）、3つのモード全部、1回で多くの問題、1回で長い練習。
  - とくべつ：朝（4〜7時）・夜（22〜4時）の練習、感想を選んだ回数、「むずかしかった」のに最後までやりきった回数。
- **ランク**：ブロンズ・シルバー・ゴールド・プラチナ・レジェンドの5段階。メダルはSVGで描き、未獲得は鍵つきのグレーで表示する。
- **獲得の保存**：到達した実績はIDと獲得日時を保存する（`earned`）。知らせ済みかどうかも保存する（`seen`）。記録が整理されても消えず、記録を消去したときは一緒に消える。
- **実績画面**：獲得数と進み具合、ランク別の獲得数、累計の数字（回数・こ数・時間・日数・最長の連続）、もうすぐ達成できる実績（上位3件）、分類ごとのメダル一覧。メダルを選ぶと、説明・進み具合・獲得日を下部に固定表示する。
- **お知らせ**：練習完了時に、新しく獲得した実績を表示する（最大3件）。ホームには「NEW」を表示し、実績画面を開くと既読にする。
- 競争・順位・共有は設けない。

## 9. 対象外（将来候補）

- アカウント・クラウド同期、通知（リマインダー）。ブラウザ内完結の方針を保つ。
- ホーム画面への追加（PWA）とオフライン対応。
- アプリ内描画と正解の重ね合わせ、自己評価の詳細化（`connection-practice.md` の将来機能）。
- 上達や正確さの自動判定。
